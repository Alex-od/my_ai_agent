# Демонстрация: RAG vs Без RAG

## Постановка задачи

Показать учителю разницу между двумя режимами работы агента:

- **Без RAG** — вопрос уходит напрямую в LLM, модель отвечает из своих общих знаний
- **С RAG** — вопрос сначала ищет релевантные чанки в базе знаний, затем LLM отвечает строго на основе найденного контекста

Цель: наглядно показать, что RAG даёт точные, конкретные ответы по документам проекта, а без RAG модель отвечает обобщённо или придумывает.

## Два экрана приложения

| Экран | Режим | Как работает |
|-------|-------|-------------|
| ChatScreen | Без RAG | MCP не подключён, запрос идёт напрямую в LLM |
| RagScreen | С RAG | MCP подключён к rag_server.py, чанки инжектируются в prompt |

---

## Этапы демонстрации

### Этап 1 — Подготовка (до показа)
Описание в файле: `01-preparation.md`
- Запустить Ollama и rag_server.py
- Проиндексировать папку forindexation через RagScreen
- Убедиться что индекс готов (статус "Готово")

### Этап 2 — Демо "Без RAG"
Описание в файле: `02-without-rag.md`
- Открыть ChatScreen (без MCP)
- Задать 10 вопросов
- Зафиксировать ответы — общие, без конкретики проекта

### Этап 3 — Демо "С RAG"
Описание в файле: `03-with-rag.md`
- Открыть RagScreen (MCP подключён, индекс готов)
- Задать те же 10 вопросов
- Показать RagResultsPanel — какие чанки были найдены
- Зафиксировать ответы — конкретные, со ссылками на источники

### Этап 4 — Сравнение результатов
Описание в файле: `04-comparison.md`
- Сравнить ответы по 10 вопросам
- Выделить категории: где RAG помог, где не помог, почему

---

## Ожидаемый результат

1. Учитель видит разницу между общим и контекстным ответом
2. Видно какие именно чанки участвовали в ответе (RagResultsPanel)
3. Понятна концепция: RAG = точность, Без RAG = широта
