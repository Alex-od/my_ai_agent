# Этап 1 — Подготовка

## Цель
Запустить все серверы и убедиться, что индекс документов готов до начала демонстрации.

## Шаги

### 1. Запустить Ollama
```
ollama serve
ollama run nomic-embed-text
```
Проверить: `http://localhost:11434` доступен

### 2. Запустить RAG сервер
```
cd mcp-server
python rag_server.py
```
Сервер стартует на порту 8083

### 3. Индексировать документы
- Открыть приложение → перейти на экран "Неделя 5: RAG"
- Нажать на панель "RAG — база знаний" (раскрыть ▼)
- Убедиться что путь: `C:\MyClaudeAgents\forindexation`
- Нажать кнопку "Старт"
- Дождаться статуса "Готово: X structural + Y fixed"

### 4. Подключить MCP
- В RagScreen нажать кнопку "MCP"
- URL: `http://192.168.0.11:8083`
- Нажать Connect
- Дождаться статуса "MCP ●" (зелёный)

## Критерий готовности
- Панель RAG показывает "Готово"
- Статус MCP: CONNECTED (●)
- В выпадающем MCP меню видны инструменты: `search_documents`, `get_indexing_status`, `compare_strategies`
