# Этап 4: UI — RagResultsPanel — расширенное отображение (ChatScreen.kt)

## Контекст
`RagResultsPanel` — collapsible-панель с результатами последнего поиска. Сейчас отображает:
- Заголовок: "N чанков найдено"
- Список карточек с: превью текста, source, section, chunk_size, score (L2)

Параметры: `results: List<RagSearchResult>`, `expanded: Boolean`, `onToggle: () -> Unit`.

## Задача
Показывать статистику фильтрации и reranker-score в карточках. Сделать статистику информативной.

## Изменения в RagResultsPanel

### Обновление сигнатуры

**Добавить параметры:**
- `searchStats: RagSearchStats?` — статистика последнего поиска (null если реранкер выключен)
- `rerankerEnabled: Boolean` — для условного отображения reranker-score в карточках

### Обновление заголовка панели

**Текущий заголовок:** `"N чанков найдено"`

**Новый заголовок (если реранкер включён и searchStats != null):**
```
"N из M чанков  •  отсеяно: K"
```
где:
- N = `searchStats.finalCount` (сколько вернули)
- M = `searchStats.retrievedCount` (сколько взяли из FAISS)
- K = `searchStats.filteredCount` (сколько отсеяли по порогу)

Если `filteredCount == 0` — не показывать "отсеяно".

**Заголовок если реранкер выключен:**
- Остаётся `"N чанков"` (как сейчас).

### Обновление карточки результата

Каждый `RagSearchResult` отображается в карточке. Добавить строку:

**Reranker score** (виден только если `rerankerEnabled && result.rerankerScore != null`):
- Иконка: 🏆 (или текст "Reranker:")
- Значение: `"0.72"` (2 знака после запятой)
- Цвет текста: градация по порогу:
  - score >= 0.7 → MaterialTheme.colorScheme.primary (зелёный оттенок)
  - score >= 0.4 → MaterialTheme.colorScheme.secondary (нейтральный)
  - score < 0.4 → MaterialTheme.colorScheme.error (красный)

**Обновление строки FAISS score:**
- Было: `"🎯 0.342"` (L2-расстояние)
- Стало: `"FAISS: 0.342"` — чтобы пользователь понимал что это другая метрика

### Обновление точки вызова RagResultsPanel

В `RagScreen.kt` или родительском composable добавить:
- `searchStats = ragLastSearchStats.collectAsState().value`
- `rerankerEnabled = ragRerankerEnabled.collectAsState().value`


## Визуальная схема заголовка панели (с реранкером)

```
▼ RAG Результаты         3 из 10 чанков • отсеяно: 4
```

## Резюме

**Что получим:** Пользователь видит полную картину работы реранкера — сколько нашли, сколько отсеяли, насколько каждый чанк релевантен по мнению cross-encoder.

**Критерии успеха:**
- Заголовок показывает "N из M" только если реранкер включён
- Reranker score в карточке виден только при включённом реранкере
- Цвет score соответствует уровню релевантности
- При выключенном реранкере UI выглядит как раньше (без регрессий)
- Приложение компилируется без ошибок
