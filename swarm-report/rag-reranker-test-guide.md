## Шаг 1 — Подключение

Открой экран **RAG**.

- `● RAG` зелёный + статус "Готово" → всё готово, переходи к шагу 2
- `○ RAG` серый → нажми на него (реконнект)
- `… RAG` → подожди 5 сек

---

## Шаг 2 — RAG без реранкера

Реранкер: **OFF**, Стратегия: Structural, Top-K: 3

**Вопрос:**
```
что такое ui builder?
```
**Проверить:**
- Ответ содержит: Compose, Clean Architecture, Decompose
- Логи → JSON → в `instructions` есть `=== КОНТЕКСТ ИЗ БАЗЫ ЗНАНИЙ ===`
- Панель результатов: `Найдено: 3 чанка`

---

## Шаг 3 — Включи реранкер

В панели "RAG — база знаний":
- Реранкер: **ON**
- Модель: `MiniLM-L6 (быстрая)`
- Порог: `0.30`, Извлечь: `10`, Вернуть: `3`

> ⚠️ Первый запрос скачает модель (~66MB) — подождать 30-60 сек

**Тот же вопрос:**
```
что такое ui builder?
```
**Проверить:**
- Заголовок: `"3 из 10 чанков"` — реранкер взял 10, вернул 3
- В карточках: `🏆 0.XX` с цветом
  - 🟢 ≥ 0.7 — релевантно
  - ⚪ 0.4–0.7 — средне
  - 🔴 < 0.4 — слабо

---

## Шаг 4 — Проверка порога

**Вопрос:**
```
как создать AI агента?
```

Порог `0.10` → заголовок: `отсеяно: 0`
Порог `0.70` → заголовок: `отсеяно: X` (больше)

Убедись что при высоком пороге "отсеяно" растёт.
